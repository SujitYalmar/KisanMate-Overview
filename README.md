# 🌾 KisanMate

KisanMate is a farmer-friendly mobile application designed to help manage farm finances, track crop-wise performance, and organize daily agricultural tasks.

## 🚀 Features

* 📱 Phone-based authentication (Firebase)
* 💰 Track income and expenses
* 🌱 Crop-wise transaction tagging
* 📊 Financial reports (date & crop-based)
* 📅 Task scheduling with reminders
* 🔍 Search, filter, edit, and delete records

## 🧩 Main Screens

* Dashboard (summary + crop cards)
* Reports (summary & crop insights)
* Tasks (schedule and reminders)
* History (transactions management)
* Profile (user info & logout)

## 🛠 Tech Stack

* Kotlin Multiplatform
* Compose Multiplatform
* Material 3
* Firebase Auth & Firestore
